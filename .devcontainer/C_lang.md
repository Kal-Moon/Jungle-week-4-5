C언어 포인터: 메모리 주소를 저장하는 변수
사용하는 이유
1. 큰 데이터를 복사하지 않고 위치만 넘겨서 효율적으로 다루기 위해
2. 함수에 변수를 넘겼을 때 원본 값 자체를 바꾸고 싶을 때
3. 배열, 동적 메모리 할당(malloc 등)다룰 때 필수

메모리? 컴퓨터가 프로그램 실행 중 데이터를 저장해두는 공간(창고라 생각해보자)
주소? 메모리 각 칸에 매겨진 고유 번호(창고 각 칸에 매겨진 고유 번호)
저장? 데이터를 주소 특정 칸에 넣어두는 행위(내용물을 창고의 특정 칸에 넣어둠)
변수? 그 칸에 붙인 이름(창고 번지에 붙인 이름)

C언어에는 변수가 크게 3타입이 있다.
int 타입 변수: 이 칸에 들어있는 값은 정수로 해석하라는 약속
char 타입 변수: 이 칸에 들어있는 값은 문자로 해석하라는 약속
포인터 타입 변수: 이 칸에 들어있는 값은 숫자가 아니라 다른 메모리 칸의 번지수로 해석하라는 약속

타입은 뭔가? 규칙이라 생각하면 된다.

변수: 변하는 수     상수: 변하지 않은 수

자료형: 변수형, 실수형, 문자형 등 여러 자료형태를 말함

%d\n, - printf 함수 안에서 숫자를 출력하고 줄을 바꿀 때 사용되는 서식 문자열. 
%d - 서식 지정자. 정수 데이터를 10진수 형태로 출력하라는 뜻. 뒤에 전달받은 정수 변수나 값을 이 위치에 대입하여 보여줌
\n - 이스케이프 문자. 줄바꿈을 의미함. 출력을 마친 후 커서를 다음 줄로 이동시킴
/* 내용 */ - /* */ 안에 있는 모든 내용은 주석처리됨
// - 주석. C99 표준부터 공식적으로 도입되었고 C99 이전의 구형 C 컴파일러에서는 오류가 발생할 수 있음

float n: 실수를 입력하는 값. 출력 시 %f 를 사용하고, %과 f사이에 .n을 입력하면 소수점 n만큼 표시할 수 있음
double n: 실수를 입력하는 값. 출력할 때 %lf(알파벳L임)를 붙이면 됨. %와 lf 사이에 .n을 입력하면 소수점 n만큼 표시할 수 있음. 이 때 뒷자리는 반올림처리

const n: n을 상수로 입력하는 값. 변하지 않게 만들어줌
int: 정수로 입력하는 값. 출력할 때 %d를 입력해야함

scanf : 키보드 입력을 받아서 저장.
scanf_s: scanf와 같은 기능. 차이가 있다면 scanf_s는 버퍼 크기를 검사하여 안전함. Microsoft Visual Studio(MSVC 컴파일러)에서 전용으로 지원하는 보안 강화 함수라 모든 곳에서 사용하지 못할 수도 있음
&n : n값이 있는 곳으로 이동. 변수 호출



++n : 문장이 수행하기 전 n을 1씩 증가시켜줌        n++ : 문장을 수행하고 나서 다음 문장에 1을 증가
ex. int n = 20;
printf("n는 %d\n", ++n);        => 21
printf("n는 %d\n", n++);        => 21
printf("n는 %d\n", n);          => 22

메모리 개념(malloc과 free)
int n; 같은 평범한 변수는 함수가 실행되는 동안에만 존재함. 함수가 끝날 경우 그 공간이 사라지거나 다른 용도로 재활용되고, 크기도 코드 작성 시점에 미리 정해져 있어야 함.
하지만 사용자가 숫자나 문자를 얼마나 만들지 모르는 경우 함수 호출 하나가 끝나더라도 살아있어야 함. 일반 변수로는 이 조건을 만족시킬 수 없음.
그래서 필요한 게 malloc과 free.
malloc은 프로그램 실행 중 원하는 만큼의 메모리 공간을 빌려옴. 일반 변수는 stack에서 데이터를 받아오고 함수가 끝나면 자동으로 청소 됌. 하지만 heap은 그러지 않음.
malloc으로 heap 공간을 빌리면, 그 공간은 free로 반납하지 전까지 안 치움.
만약 free를 안 할 경우 heap에 공간이 계속 쌓이기만 하고 없어지지 않음. 이를 '메모리 누수'라 부름
