C언어는 무엇인가?
1972년 벨 연구소의 데니스 리치가 개발한 절차적 프로그래밍 언어로, 하드웨어 제어와 효율성이 뛰어난 범용 언어다.

C언어를 배우는 이유
운영체제 작성을 목표로 한 언어
-하드웨어적인 부분까지 프로그래머가 다룰 수 있음
절차지향적 언어지만
-많은 객체 지향적 언어들의 근간이 됨

장점
-컴퓨터 전반에 대한 지식을 고루 알게 됨
-가장 작은 프로그램으로 가장 빠른 프로그램 작성가능

단점
-습득에 시간과 노력이 필요

Pintos와 C언어는 무슨 관계일까?
-핀토스는 C언어로 만들어진 운영체제 프로그램이다
-대부분 C언어로 작성되기 때문에 핀토스를 하려면 C언어는 잘하면 좋다!

C언어 포인터: 메모리 주소를 저장하는 변수
사용하는 이유
1. 큰 데이터를 복사하지 않고 위치만 넘겨서 효율적으로 다루기 위해
2. 함수에 변수를 넘겼을 때 원본 값 자체를 바꾸고 싶을 때
3. 배열, 동적 메모리 할당(malloc 등)다룰 때 필수

메모리? 컴퓨터가 프로그램 실행 중 데이터를 저장해두는 공간(창고라 생각해보자)
주소? 메모리 각 칸에 매겨진 고유 번호(창고 각 칸에 매겨진 고유 번호)
저장? 데이터를 주소 특정 칸에 넣어두는 행위(내용물을 창고의 특정 칸에 넣어둠)
변수? 그 칸에 붙인 이름(창고 번지에 붙인 이름)

C언어에는 변수가 크게 3타입이 있다.
int 타입 변수: 이 칸에 들어있는 값은 정수로 해석하라는 약속
char 타입 변수: 이 칸에 들어있는 값은 문자로 해석하라는 약속
포인터 타입 변수: 이 칸에 들어있는 값은 숫자가 아니라 다른 메모리 칸의 번지수로 해석하라는 약속

타입은 뭔가? 규칙이라 생각하면 된다.
